# Architecture decision records

Short, numbered, immutable records of decisions that shape the codebase.

**When required.** Before product work in any pause class listed in [`AGENTS.md`](../../AGENTS.md) (contracts and SVM programs, indexer schema or reindex, money and settlement, verification and disputes, bridge and custody, commercial registry and deploys, auth and keys), open an ADR as its own PR and get maintainer approval first.

**Statuses.** `Proposed` · `Accepted` · `Superseded by NNNN`.

**Index.** Seeded ADRs and the template land in a follow-on docs PR. Until then, new decisions still use the ADR shape: Context · Decision · One rejected alternative and why · Consequences · Status.
