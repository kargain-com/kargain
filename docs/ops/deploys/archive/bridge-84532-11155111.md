## Execution order

### 1. Redeploy hub adapter (`1.1.0-rc.1`)

```bash
pnpm deploy:adapter:sepolia --force
```

- Overwrites `bridgeGateway` in `deployments/84532.json`
- Pushes prior address into `historical.bridgeGateway[]`
- Prints the **new** adapter address

Recorded adapter: `0xC219bf834B8965339b95C0B6Afe3c4d0F1266Fb0` (block 44392489)

### 2. Deploy spoke ONFT

```bash
pnpm deploy:spoke:sepolia
```

Recorded spoke: `0x5b7fD0ffF9B82255AD4d043a491e81948b76e703` (block 11312959)

### 3. Verify (best-effort explorer)

```bash
pnpm verify:sepolia
pnpm verify:spoke:sepolia
```

Hub verify includes the adapter target from the **updated** manifest address.
Both contracts verified on Basescan / Etherscan (July 20, 2026).

### 4. Approve new adapter (hub KarPassport)

Adapter address must be the **new** `bridgeGateway` from step 1.

```bash
# cast (Foundry) — replace ADAPTER and TOKEN_CONTRACT
cast send "$KAR_PASSPORT" \
  "setApprovalForAll(address,bool)" \
  "$ADAPTER" true \
  --rpc-url "$BASE_SEPOLIA_RPC_URL" \
  --private-key "$DEPLOYER_PRIVATE_KEY"
```

Or Hardhat console / a one-off script using `KarPassport.setApprovalForAll(adapter, true)`.

### 5. Wire pathway (§7.6)

```bash
pnpm bridge:wire
pnpm bridge:wire:read-only
```

`bridge:wire:read-only` must print **§7.6 asserts: PASS** (green gate).
Recorded `pathwayConfigHash`: `0x3ef27aa72ed7b2d5aadf100d99d4dfd4fa1e2b1adc915523b0ddc8c9bf2d517e`

**July 20, 2026:** `bridge:wire:read-only` exit **0**, §7.6 PASS.

`bridge:wire` reads the hub OApp from `deployments/84532.json` — no hardcodes;
the new adapter from step 1 is picked up automatically.

### 6. Live smoke E2E (testnet only)

**Requires `--token-id`.** Auto-mint is disabled (SPEC §7.6 Phase 2 (e)). Pre-mint a home passport with **valid** metadata (UI or explicit `mintPassport`), then:

```bash
pnpm smoke:bridge --token-id <TOKEN_ID>
# optional partial: --skip-return
```

Mainnet live smoke is refused by policy. Home KarPassport has **no user burn** — do not create leftover commercial NFTs for smoke; use a dedicated ops wallet when possible.

## Troubleshooting

| Symptom | Action |
|---------|--------|
| `deploy:adapter` refuses without `--force` | Intentional overwrite guard — pass `--force` (`HARDHAT_NETWORK` script; not Hardhat `-- --force`) |
| Public RPC rejects writes | Bridge scripts use `scripts/lib/deployer-viem.ts` (local Account → eth_sendRawTransaction). Re-run `pnpm bridge:wire` / `smoke:bridge`. |
| `bridge:wire:read-only` FAIL | Fix ULN/DVN/enforcedOptions; re-check DVN table above; do not smoke |
| Smoke preflight approval | Run `setApprovalForAll` for the **new** adapter |
| Smoke listed / DISPUTED revert | Use a VERIFIED, unlisted, non-auction passport |
| Smoke delivery timeout | Check LZ Scan by GUID; confirm peer/enforcedOptions; wait/retry |
| Spoke already deployed | `deploy:spoke:sepolia` aborts if `karPassportOnft` set — expected |
