# Security policy

## Reporting a vulnerability

Report security issues through [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on this repository.

Do not open a public issue, pull request, or discussion for a vulnerability.

There is no personal contact address for security reports.

## Scope

In scope:

- Smart contracts
- SVM programs
- Application (web client and supporting libraries)
- Indexer (Ponder and SVM ingest)

## Deployments

All deployments today are testnet. Treat findings accordingly; do not assume mainnet production exposure.

## Bounty

There is no bug bounty program.

## Response

Reports are handled on a best-effort basis. There is no guaranteed response time.
